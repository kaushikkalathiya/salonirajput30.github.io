Background

How I work with WordPress

I am a WordPress and WooCommerce developer with over four years of professional experience building custom themes, plugins and ecommerce sites for client projects. I work comfortably with ACF and custom post types, move static HTML sites onto WordPress, customise WooCommerce templates and checkout flows, and audit older sites for speed and technical SEO.

I take projects from design references and static HTML through to maintainable WordPress builds, using custom PHP code in place of extra plugins where it reduces page weight. I follow WordPress security practices including nonces, data sanitisation and capability checks, and build with Core Web Vitals and on-page SEO in mind from the start.

Most recently at WebbyGenius Infotech, I built REST API based business applications with authentication and input validation for frontend teams and third-party systems. I also have experience with server setup, deployment and configuration.

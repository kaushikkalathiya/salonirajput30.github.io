My story

I started with a Master of Computer Application from Gujarat Technological University, then moved straight into professional development — where I learned that the difference between a good WordPress site and a great one comes down to the decisions most people never see.

Over four years across three companies — Tecocraft, Triospire and Narola Infotech — I've worked on everything from migrating static HTML sites into managed WordPress platforms, to building complex WooCommerce flows, custom REST API endpoints, and deep performance audits that produced measurable, verifiable results.

My approach is deliberately technical. I don't treat WordPress as a drag-and-drop tool — I treat it as a platform with a serious architecture that rewards careful plugin selection, clean PHP, disciplined use of ACF and custom post types, and an uncompromising focus on load performance and Core Web Vitals.

Philosophy

How I approach every project

Technical decisions made early in a project have a disproportionate impact on everything that follows. I've seen what happens when those decisions are rushed — and I build accordingly.

01
Performance is not optional

Every build is tested for Core Web Vitals from day one. Speed is an architectural decision, not a last-minute fix. Slow sites cost real money.

02
Clean, maintainable code

Code that only you understand is a liability. I write for the team or developer who inherits the project next — readable, documented, and following WordPress coding standards.

03
Security by design

Nonces, data sanitisation, capability checks, minimal plugin footprint and regular auditing. Security practices built into the workflow, not bolted on afterwards.

04
Scalable architecture

Choosing CPTs, ACF, and REST API design that supports growth. Sites that won't need rearchitecting six months after launch because the data model was thought through properly.

05
SEO is structural

Semantic HTML, proper heading hierarchy, schema markup, site speed — these are structural decisions. SEO isn't a plugin; it's how the site is built.

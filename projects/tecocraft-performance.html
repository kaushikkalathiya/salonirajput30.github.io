Overview

During my time at Tecocraft as a Backend & Performance Specialist, I worked across multiple client WordPress websites that had accumulated significant technical debt. Sites were slow, poorly structured and failing on Core Web Vitals measurements — problems that were directly impacting both organic search rankings and user retention.

The project involved conducting systematic technical audits across these legacy builds and implementing targeted fixes to address the root causes of poor performance and SEO scores.

Challenge

The WordPress installations inherited at Tecocraft had several common issues that had compounded over time:

  • Plugin bloat: Dozens of poorly maintained plugins causing redundant JavaScript and CSS loading on every page.
  • Unindexed database queries: Slow, unoptimised MySQL queries running on high-traffic pages with no caching layer.
  • Render-blocking resources: CSS and JavaScript loaded synchronously in the document head, blocking first contentful paint.
  • Missing caching strategy: No page caching, no object caching, no browser cache headers configured.
  • Unoptimised assets: Large uncompressed images, no lazy loading, and no CDN in use.
  • Poor technical SEO: Missing or duplicate meta tags, unstructured content, no schema markup, crawl inefficiencies.
Solution & Implementation

I approached each site methodically — beginning with a full technical audit before making any changes. This ensured that every action was targeted at a verified problem rather than making speculative improvements.

Plugin audit and elimination

Conducted a full plugin review, replacing multiple single-purpose plugins with leaner custom PHP code where appropriate. Removed all plugins that were loading resources on pages where they weren't used, using conditional loading to restrict plugin assets to only the templates that required them.

Database optimisation

Identified slow queries through MySQL slow query logging and WordPress query monitoring. Added appropriate database indexes, refactored expensive post meta queries, and implemented WordPress Transients API to cache the results of heavy queries.

Asset delivery optimisation

Moved non-critical JavaScript to the footer. Implemented deferred and async loading where appropriate. Converted above-the-fold CSS to inline critical CSS to eliminate render-blocking stylesheets. Compressed and served images in next-generation formats with explicit width and height attributes to eliminate CLS.

Caching strategy

Implemented a layered caching strategy including full-page caching, object caching, and browser cache headers. Configured appropriate cache expiry for static assets and set up cache invalidation rules for dynamic content types.

Technical SEO improvements

Audited and corrected all meta tag issues, resolved duplicate content problems, implemented structured data markup, optimised internal linking structure, fixed crawl errors and improved overall page structure for both search engines and users.

Tecocraft Performance and SEO Audit

Technical audit and refactor of older client WordPress sites to resolve slow database queries, heavy plugin footprints, missing caching and technical SEO gaps.

Company
Tecocraft Infusion Pvt. Ltd.
Role
WordPress Developer (CMS)
Period
Feb 2021 to Feb 2023
Focus
Speed, Caching & Technical SEO

Problem

Older client WordPress sites inherited at Tecocraft Infusion Pvt. Ltd. suffered from heavy plugin usage, unoptimised database queries, synchronous scripts, uncompressed images, no page or object caching, and incomplete meta tags and structured data.

Approach

I audited each site before making changes so every fix targeted a measured bottleneck.

Plugin review and conditional loading

Replaced redundant single-purpose plugins with lean custom PHP where appropriate and restricted plugin assets to load only on templates that required them.

Database queries and caching

Identified slow queries, added Transients API caching for expensive lookups, and configured page and object caching layers.

Front-end assets and technical SEO

Deferred non-critical scripts, optimised images, and corrected meta tags and structured data markup across templates.

Technologies

WordPressPHPMySQLACFTransients APIPage & Object CachingSchema Markup

Outcome

Across the audited Tecocraft sites, the combined speed, caching and technical SEO work delivered a 2.4 times improvement in page speed, a 45 percent increase in SEO score and a 27 percent increase in user engagement.

BreathingCenter

Migrated a static HTML health and wellness website to WordPress at Tecocraft, implementing ACF-powered Custom Post Types for structured content management and SEO optimisation.

Overview

BreathingCenter's static HTML website presented limitations in content management and discoverability. The health and wellness sector requires regular content updates — articles, programme information, practitioner profiles — none of which was practical to manage in a static HTML environment. The project required a full migration to WordPress with a content architecture that matched the site's specific content types.

Challenge

Health and wellness websites typically have several distinct content types — services, conditions treated, practitioner information, articles — that benefit from dedicated content models rather than generic page templates. The existing static site had no such structure, making migration an opportunity to redesign the content architecture from scratch.

Solution & Implementation

HTML to WordPress conversion

Converted the existing static HTML and CSS into a WordPress custom theme, maintaining the visual design while introducing the WordPress template hierarchy and content management infrastructure.

ACF and Custom Post Types

Designed and registered Custom Post Types for the site's key content categories. Used Advanced Custom Fields (ACF) to provide structured data entry fields for each content type — ensuring consistent data capture and predictable front-end display.

SEO optimisation

Applied technical SEO improvements throughout the migration — proper heading hierarchy, meta tag implementation, structured data for health-related content types, and clean URL structures that preserved link equity from the existing site.

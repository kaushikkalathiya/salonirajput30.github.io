BreathingCenter

Migrated a static HTML health and wellness website to a responsive WordPress build at Tecocraft Infusion Pvt. Ltd. using ACF and custom post types.

Company
Tecocraft Infusion Pvt. Ltd.
Role
WordPress Developer (CMS)
Period
Feb 2021 to Feb 2023
Category
HTML to WordPress · ACF & CPT

Problem

BreathingCenter ran on static HTML, making regular updates to programmes, articles and practitioner content slow and dependent on manual HTML edits.

Approach

Converted the static HTML and CSS into a responsive custom WordPress theme at Tecocraft Infusion Pvt. Ltd., registering custom post types and ACF field groups for structured content management and on-page SEO.

Technologies

WordPressACFCustom Post TypesPHPHTML/CSS

Outcome

Delivered a responsive WordPress CMS where content categories are structured cleanly and managed directly in the WordPress dashboard.

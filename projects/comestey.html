Comestey

WooCommerce store built with Gutenberg blocks for dynamic product layouts, custom PHP styling and a scalable product management architecture designed for growth.

Company
Triospire
Role
Senior WordPress Developer
Period
May 2023 – July 2024
Category
WooCommerce · Gutenberg
Overview

Comestey required a WooCommerce-based e-commerce platform that was both visually engaging and easy for the client team to manage and expand. The decision to use Gutenberg as the content-building layer rather than a third-party page builder was deliberate — it provided a lighter, more performant foundation that would serve the site better as the product catalogue grew.

Challenge

Building a visually rich WooCommerce store using Gutenberg required a more custom approach than a typical page builder workflow. The default WooCommerce Gutenberg blocks provide limited styling control, requiring custom PHP and CSS work to achieve the required product display and layout behaviour.

Solution & Implementation

Gutenberg-based build

Built the site using the WordPress block editor throughout — taking advantage of the performance benefits of a page-builder-free WordPress installation. Custom block patterns were created for frequently used layout combinations.

WooCommerce customisation

Extended WooCommerce's default block templates and PHP templates to implement the required product display designs. Custom CSS was applied to WooCommerce-specific elements to ensure visual consistency across the shopping experience.

Scalable product management

Configured WooCommerce's product taxonomy and attribute system to support the client's catalogue structure, making it straightforward to add new products and categories without developer involvement.
